# Fala 0.14.2 — meaningful capoeira conversations

Release source: `f33c0c1c0105651ca9e2e7c851a8d953f7ca1f77`. App identity remains `com.fala.app`, using the existing signing identity.

## Behavior and diagnosis

The owner's 0.14.1 screenshot showed a cord described as something to hear and left untranslated in Hebrew. The universal hear/repeat-name models and mandatory exact focus term encouraged this behavior across unrelated lesson topics. This release removes the continuation script and exact-term requirement, supplies situational beginner openings and prioritizes the learner's answer over the teaching schedule. Cord descriptions have literal Hebrew/English meanings; narrow validation guards cover the reported misuse and untranslated descriptions. Native progress numbers use LTR inside the Hebrew interface.

See [lesson quality](../lesson-quality.md) for the root cause, designed acceptance exchanges, live evaluation procedure and limits. Saved messages remain unchanged; a new conversation avoids carrying the old script as history. Server corrections reach existing clients on new requests without reinstalling. The native counter fix requires the new Android binary. No database migration, provider change or extra AI request was introduced.
