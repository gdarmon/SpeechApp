## Behavior and source changes

### Hebrew and English interface

Added the shared `locales/he.json` catalog and `scripts/localization.mjs` generator, producing `public/app/i18n-catalog.js` and native `UiCatalog.kt`. Native UI uses `UiLanguage.kt`; web uses `i18n.js`. Menus, settings, rewards, help and relevant accessibility text use the selected UI language. Hebrew layout is RTL and Portuguese text remains LTR.

Account preference `reward_profiles.ui_language` persists the selection. Saved session translations retain their original language, so opening history does not change the application language. The native selector is labeled App language and is available near the top of account settings.

### Default reminders

The migration added account language and the one-time `reminder_defaults_applied` marker. New reminders default to enabled at minute 1020 (17:00). Existing disabled profiles received that default; existing enabled custom times were retained. Later opt-outs survive migration reruns.

The production transaction verified all 22 existing profiles, expected reminder changes, preserved unrelated profile data and unchanged RLS/denied public-role access, with zero mismatches. No individual profile data was exported into this record.

Android asks once for notification permission after the signed-in Home screen has loaded an enabled reminder. Web requests permission through the first Talk gesture when supported/configured, respects denial and explicit disconnection, and avoids repeated registration. The first registration completes before the new-conversation mutation to avoid competing account writes. Existing same-day practice/deduplication and approximate delivery behavior remain.

### Reply ideas and playback

Reviewed beginner examples now adapt their suggestions to the current question intent instead of repeatedly suggesting the same pair. Coaching validation rejects an unchanged pair on a changed question except appropriate help/repair cases. Prompt guidance reinforces matching the current question.

Normal native playback no longer obeys the AI's `pace: slow` field. Explicit Slow still uses 45% speed. Web voice generation asks for clear natural pacing without stretched syllables; the misleading 0.8× label was removed.

These fixes were initially prepared locally under 0.13.8, whose notes remain in `releases/`. There was no separate 0.13.8 publication during this work; they shipped in 0.14.0.
