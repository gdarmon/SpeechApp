# Fala 0.15.0 — home review and Vercel milestone

Prepared on 27 September 2026. Publication receipts are recorded below once verified. The owner explicitly requested the fix and release to 0.15.0; the established targets are the website, Google Play Internal Testing and closed Alpha, not Production.

## What changed

Android's old “Today's focus” card always read the first correction, or the first help phrase when no correction existed. The label implied daily/lesson selection that did not exist. The reported `a posição do pé` was saved practice data, not a hardcoded lesson or a sign that the learner was failing to progress.

The server now derives one optional `review_phrase` from recent account-owned corrections, help and vocabulary from the five latest completed conversations. Up to ten distinct candidates seen in the past 30 days rotate by UTC day and completed-conversation count; selection is stable on refresh. A single candidate may repeat, and no candidate means no card. Old history is retained. Both clients use **From your recent practice** and an optional recall prompt, with Hebrew/English labels and Portuguese LTR text. No extra AI call, SQL round trip or schema migration is needed.

0.15.0 is the owner-requested visible Vercel milestone. The actual website/API migration and Android origin change already shipped in [0.14.4](0.14.4.md). Existing keys, Google clients, account database, `com.fala.app` identity and signing key are retained. Visible web/native versions, cache version, fallback Android code and English release notes are updated together.

## Validation

- Clean npm 10.9.7 installation, 221 backend tests, TypeScript/build, release metadata and generated catalogs passed. The default suite skips the opt-in PostgreSQL concurrency test; CI runs it separately.
- Regression tests cover the reported pinned phrase, all available candidates, completion/day rotation, stable refreshes, duplicate/expired/invalid data, help-only history, account isolation and learning-data deletion.
- All four browser suites passed. The review card updates from the dashboard, hides null/missing suggestions without the old first-item fallback, and preserves Portuguese under Hebrew layout.
- Android unit tests, debug build, lint and instrumentation compilation passed with Java 21. No physical phone or actual microphone/notification test is claimed. Remote publication results follow below.

The full-session 50-user real-AI timing in 0.14.4 remains the latest measurement: 50/50 sessions, 600/600 operations, p50 2.487 s and p95 3.316 s. That still misses the strict three-second target. This release does not change generation or provider capacity, and does not claim a new latency measurement.
