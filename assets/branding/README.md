# Fala logo

`fala-logo.png` is the original generated PNG, with transparency preserved. The same asset is bundled in Android and in the Netlify landing page. The Android adaptive icon supplies the forest-green background and a safe inset for round/squircle masks.

Generated with Codex's built-in image-generation tool (not the API/CLI fallback). Final prompt:

> Use case: logo-brand. Create a finished square Android app icon for a Brazilian Portuguese conversation app. Exact only text: "Fala" (capital F, lowercase a l a), extremely legible, bold friendly custom rounded lettering, integrated with one simple speech bubble. Match existing app palette: deep forest green #12664F and warm cream #FFFCF5. Restrained, warm, confident, adult learning app. Flat crisp vector-like raster logo; no 3D, no shadows, no gradients, no textures, no flag, no mascot, no mockup, no slogan, no watermark. Full-bleed solid green square background, no pre-rounded outer corners. Cream speech-bubble/wordmark centered; all essential letterforms and bubble tail within central 62 percent of square so circular Android masks will not clip it. Single icon only, 1024x1024.

The tool returned a transparent 1254 × 1254 wordmark. The consuming app/page adds the green background; the original is retained without raster edits.
