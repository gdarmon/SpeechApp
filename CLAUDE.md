# Fala project instructions

@AGENTS.md

Read `docs/agent-handoff.md` when starting work in this repository. Follow links for the specific subsystem you change rather than loading every document.

Project skills are in `.claude/skills/`: `fala-release` for preparing/publishing/verifying releases and `fala-debug` for investigating reported behavior. The source of the release procedure is `docs/releasing.md`; the source of current release evidence is `docs/releases/`.
